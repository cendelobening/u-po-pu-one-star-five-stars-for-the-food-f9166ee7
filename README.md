## Entry

> One star: the locals ask "how are you" and walk off before I can answer, but the ramen broth alone was worth the nine-light-year flight.

One sentence, 136 characters: an alien tourist's one-star review of Earth that
complains about a baffling human habit and lands a real compliment about the food.

## How to run

```sh
python3 main.py
```

`main.py` writes the entry sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and sets the file mode to `0644`. Pure Python
standard library only; the output is deterministic.
